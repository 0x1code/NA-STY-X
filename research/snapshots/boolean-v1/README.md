# Исходники исторического замера Boolean v1

Сохранены файлы, чьи хеши перечислены в
`research/results/sbox-boolean-build-v1.json` основного проекта.
Это набор входных исходников для проверки происхождения измерений, а не отдельный
готовый Cargo workspace. Полное прежнее дерево находится в Git-коммите `1aa8680`.

Текущий пример `compare_sboxes` подключает непосредственно сохранённую функцию
подстановки и сравнивает её с новой в одном процессе. Старый JSON и ASM не
перезаписываются. `research/record_hardened_build.py` создаёт новые измерения.

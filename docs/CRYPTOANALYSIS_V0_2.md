# NA&STY-X Lab — версия 0.2

Методика DDT, знакового преобразования Уолша, SAC и условных парных корреляций описана в историческом `CRYPTOANALYSIS.md`. Его численные результаты относятся к v0.1. Актуальные результаты находятся в `research/results/v0.2-phase2-smoke.json`; происхождение новой таблицы — в `SBOX_V0_2.md`.

## Проверенные свойства

- Полная собственная таблица является перестановкой; Python и Rust независимо воспроизводят все 256 элементов.
- Точные DDT и Walsh-таблицы вычислены перебором: DU 10, максимальный модуль Уолша 64, минимальная нелинейность компонент 96.
- Проверена обратимость блочного преобразования и совпадение 185 общих векторов для 8, 12, 16, 20, 24 раундов.
- Для 32 пар ключ/блок с seed 20261011 измерены лавинный эффект, SAC, условные BIC-корреляции и средние зависимости после первых 24 раундов. Для 16 раундов средние дистанции: 64,0225 при изменении блока и 63,9470 при изменении ключа, из 128 битов.
- Проверена малая семья 256 ключей из повторяющегося байта. Она не покрывает пространство слабых или родственных ключей.

Почти половина изменённых битов не означает стойкости. Выборка 32 мала для оценки экстремальных корреляций. Новая S-box слабее старой по опубликованным дифференциальным и линейным показателям; полный шифр нельзя оценить только по ним.

## Воспроизведение

```powershell
py -3 research/sbox_design.py --check
py -3 research/generate_vectors.py --check
py -3 -m unittest discover -s tests -v
py -3 research/lab.py --samples 32 --seed 20261011 --output research/results/v0.2-phase2-smoke.json
cargo test --workspace --locked
```

Отчёт сохраняет версию шифра, seed, размер выборки, порядок битов, Python, платформу, время и SHA-256 исходников `reference.py` и `sbox.py` после нормализации переводов строк. Время и метаданные среды могут отличаться между запусками; численные таблицы при той же версии и seed воспроизводимы. Генератор открытых экспериментов не предназначен для секретов.

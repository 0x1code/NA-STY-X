# Точный анализ уменьшенной модели NA&STY-X

## Граница эксперимента

`research/reduced_model.py` реализует **отдельную игрушечную модель**, не уменьшение только числа раундов действующего шифра. Блок имеет 16 битов, половины — 8, ключ — 32. Все 65 536 входов перебираются для каждой фиксированной пары ключа и числа раундов. Изменения ширины слов существенно меняют конструкцию, поэтому результаты не являются вероятностями атак на 128-битный NA&STY-X.

Фиксированные открытые ключи: `00000000`, `76543210`. Числа раундов: 1, 2, 3, 4, 6, 8. Ключи не выбирались по результатам измерений.

## Полная спецификация модели

Ключ разбивается на четыре big-endian байта `a,b,c,d`. Все суммы ограничиваются младшими 8 битами, вращения выполняются на байте с остатком величины по модулю 8. Для раунда `i`, начиная с нуля:

```text
k[i] = ((a + ROTL8(b,13) + 0x15*(i+1)) mod 256) XOR ROTL8(c,29) XOR d
(a,b,c,d) = (b,c,d, (k[i] + ROTL8(old_a,7)) mod 256)
z = S[x XOR k[i]]
F8(x,k[i]) = ((z + ROTL8(z,17)) mod 256) XOR ROTL8(z,41) XOR k[i]
(L,R) = (R, L XOR F8(R,k[i]))
```

`S` — собственная S-box v0.2, кандидат 18. В модели только один байт вместо восьми, поэтому перестановка байтов отсутствует. Константа `0x15` — младший байт константы расписания действующего шифра. Выход: `(L << 8) | R`, без финального обмена. Обратные раунды используют те же таблицы в обратном порядке.

**Важное искажение модели:** вращения на 17 и 41 превращаются в одно и то же вращение на 1. В полном шифре это различные операции на 64-битных словах. Такая модель пригодна для отладки анализа и наблюдения структурных зависимостей, но не для переноса оценок стойкости.

## Дифференциалы

Для каждой из 16 однобитных входных разностей `a` вычисляется полная строка:

`D[a,b] = # {x : E(x) XOR E(x XOR a) = b}`.

Все входы и выходные разности покрыты для выбранного `a`. Сохраняются максимальный счётчик, минимальная выходная разность при равенстве максимумов, число равных максимумов и точная вероятность `D/65536`. Это максимум **в выбранных 16 строках**, а не во всей DDT с 65 535 ненулевыми строками.

## Линейные связи

Для каждой из 16 однобитных выходных масок `b` вычисляются все 65 535 ненулевых входных масок:

`W[a,b] = sum_x (-1)^(parity(a AND x) XOR parity(b AND E(x)))`.

Сохраняются минимальная входная маска при равенстве максимумов, знаковый коэффициент Уолша, число равных максимумов и модуль корреляции `|W|/65536`. Выходные маски ограничены выбранной семьёй; глобальный максимум всей LAT не заявляется. Вероятность совпадения паритетов для конкретного знакового коэффициента равна `(1 + W/65536)/2`; корреляция не является вероятностью восстановления ключа.

Вычисления непосредственно используют фиксированную перестановку. Вероятности отдельных раундов не перемножаются с необоснованным предположением независимости. Различие фиксированного ключа и вероятностных моделей существенно для криптоанализа: см. [Differential Cryptanalysis in the Fixed-Key Model](https://eprint.iacr.org/2022/837.pdf).

## Контрольные примеры и результаты

Для одного раунда разность левой половины проходит в правую с вероятностью 1; левая выходная половина точно равна правой входной. Это ожидаемые связи одного раунда Фейстеля, проверенные отдельным тестом.

Для двух раундов обоих выбранных ключей максимум по выбранным разностям равен `2048/65536 = 0.03125`, модуль корреляции — `15360/65536 = 0.234375`. Полные свидетельства для всех исследованных случаев находятся в `research/results/reduced-model-v1.json`.

Для ориентира тем же способом исследуется одна случайная перестановка с публичным seed 20261011. Это иллюстрация масштаба наблюдаемых экстремумов, а не критерий безопасности или распределение идеального шифра. Улучшение показателей с ростом числа раундов не доказывает стойкости.

## Воспроизведение и проверки

```powershell
py -3 research/reduced_model.py --output research/results/reduced-model-v1.json
py -3 -m unittest discover -s tests -v
```

Отчёт содержит области перебора, маски, ключи, результаты, версии среды, время и хеши исходников модели и S-box с нормализацией переводов строк. Тесты проверяют transform против прямого определения на малой перестановке, дифференциальные строки, точные связи одного раунда и обратимость всех 65 536 блоков восьмираундовой модели.

Локально прошли 18 тестов Python и 5 тестов Rust; Clippy завершился без предупреждений. Опубликованные сильнейшие выбранные свидетельства последнего восьмираундового случая отдельно пересчитаны прямым перебором, а хеши исходников отчёта проверены. 185 векторов действующего 128-битного шифра не изменились и прошли проверку генератором.

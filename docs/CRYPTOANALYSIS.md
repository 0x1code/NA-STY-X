## Точные вычисления для S-box

Перебираются все 256 входов для всех входных разностей и все маски для преобразования Уолша:

- `DDT[a][b] = # {x: S(x) XOR S(x XOR a) = b}`.
- `W[a][b] = sum_x (-1)^(parity(a AND x) XOR parity(b AND S(x)))`.
- Нелинейность компоненты: `128 - max_a |W[a][b]| / 2`, где `b != 0`.

Здесь LAT представлена знаковой суммой Уолша, а не количеством совпадений или смещением от 128. Это различие явно записано в JSON.

Получены ожидаемые свойства используемой стандартной AES S-box: биективность, дифференциальная равномерность 4, максимальная дифференциальная вероятность для ненулевого входа 4/256, максимальный модуль Уолша 32 и минимальная нелинейность компоненты 112. Все DDT и Walsh-таблицы сохранены в отчёте. Свойства S-box не переносятся автоматически на сеть Фейстеля и расписание ключей.

## Диффузия и зависимости

Для каждого числа раундов 8, 12, 16, 20, 24:

- 32 независимо выбранные пары публичных ключа и блока.
- Отдельно меняется каждый из 128 битов блока и каждый из 256 битов ключа.
- Для каждого входного бита сохраняются 128 счётчиков изменений выходных битов (SAC).
- BIC измеряет корреляцию Пирсона пар выходных индикаторов **отдельно для каждого изменённого входного бита**. Константные столбцы не имеют определённой корреляции и считаются отдельно.
- В отдельном опыте фиксируется средняя дистанция Хэмминга после каждого из первых 24 раундов.

Нумерация битов: сначала байт 0, внутри байта сначала младший бит. Входные слова шифра по-прежнему big-endian, как в спецификации.

Для 16 раундов предварительная выборка дала среднее 64,0791 изменённых выходных битов при изменении блока и 63,9604 при изменении ключа, из 128. **Это не доказательство криптостойкости.** При 32 испытаниях на каждый входной бит максимальные SAC-смещения и BIC-корреляции шумны; по ним нельзя заключить ни наличие атаки, ни независимость битов. Размер выборки указывается у каждой таблицы.

## Ключи

Исследована только узкая семья из 256 ключей, заполненных одним повторяющимся байтом. В ней найдено 256 различных полных расписаний на 24 раунда и не найдено повторяющихся раундовых слов внутри расписания. Это проверка небольшой семьи, а не поиск всех слабых или эквивалентных ключей.

## Согласование реализаций

185 общих векторов включают нулевые, единичные, последовательные, чередующиеся, старшие биты и детерминированные случайные значения. Python создаёт JSON и TSV; независимая реализация Rust проверяет шифрование и обратное расшифрование каждого TSV-вектора. Исходный 16-раундовый вектор остаётся неизменным.

## Что ещё не исследовано

Полноценные дифференциальные и линейные атаки на уменьшенную сеть, вероятность составных trails и hulls, родственные ключи вне малой семьи, формальные границы безопасности, побочные каналы, независимый аудит и сравнение скорости с AES-256/ChaCha20 ещё не выполнены. Хорошая диффузия не заменяет эти исследования.

# Исследовательская итерация v0.1 — 11 октября 2026

Исторический отчёт до замены S-box; текущая версия описана в `SBOX_V0_2.md`.

## Выполнено

- Собрана и проверена реализация Rust; исходный 16-раундовый вектор сохранён.
- В Rust и Python добавлены явные варианты 8, 12, 16, 20, 24 раунда.
- Опубликованы 185 общих векторов с проверкой шифрования и обратного расшифрования обеими реализациями.
- Добавлена лаборатория DDT, знакового преобразования Уолша, нелинейности компонент, лавинного эффекта блока/ключа, SAC, условных парных корреляций BIC и диффузии по раундам.
- Опубликован предварительный отчёт `research/results/phase2-smoke.json`: 32 пары ключ/блок, seed 20261011, все пять вариантов, полные таблицы и метаданные.
- Настроены CI-проверки Rust для Linux, Windows, macOS и минимальной версии 1.74; Python проверяет тесты, воспроизводимость векторов и короткий запуск лаборатории. Удалённые проверки должны подтверждаться результатами GitHub Actions.

## Проверки после восстановления работы

Локальная среда: Windows, Python 3.12.10, Rust/Cargo 1.99.0, target `x86_64-pc-windows-gnu`.

```powershell
py -3 -m unittest discover -s tests -v
py -3 research/generate_vectors.py --check
cargo +stable-x86_64-pc-windows-gnu test --workspace --locked
cargo +stable-x86_64-pc-windows-gnu fmt --all --check
cargo +stable-x86_64-pc-windows-gnu clippy --workspace --all-targets --locked -- -D warnings
```

Результат: 11 тестов Python, 3 модульных теста Rust и 1 интеграционный тест по 185 векторам прошли; форматирование и Clippy прошли без предупреждений.

## Наблюдения и границы

Для стандартной AES S-box точно получены дифференциальная равномерность 4, максимальный модуль Уолша 32 и минимальная нелинейность компонент 112. Для 16 раундов среднее число изменённых битов составило 64,0791 при изменении бита блока и 63,9604 при изменении бита ключа из 128. В узкой семье 256 повторяющихся байтовых ключей расписания различны.

Эти результаты характеризуют компоненты и небольшую выборку. Они не доказывают криптостойкость сети и не исключают слабые, эквивалентные или родственные ключи. Шифр не предназначен для защиты реальных данных.

Следующий исследовательский этап: поиск дифференциальных и линейных trails на уменьшенных моделях, расширение анализа расписания ключей и воспроизводимые замеры скорости. Защищённый протокол со стандартными примитивами — отдельный этап со своей спецификацией и моделью угроз.

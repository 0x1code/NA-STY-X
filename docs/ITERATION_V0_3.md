# Итерация v0.3 — ядро и сообщения

**Дата:** 12 октября 2026, Europe/Moscow. **Статус:** рабочая исследовательская реализация пунктов 1–2 плана; готовность для реальных секретов не установлена.

## Реализовано

- Новое отдельное ядро `nastyx-engine` v0.3; прежний `nastyx-core` v0.2 и его векторы сохранены.
- Собственная S-box улучшена двумя воспроизводимыми поисками: DU 10 → 8, минимальная нелинейность 96 → 102. Поиск не доказывает стойкости.
- Три последовательных ARX-преобразования и нелинейное расписание, включая четвёртое слово до финальной обработки раундового ключа.
- Измерения настоящей 64-битной функции и 128-битной сети, анализ компонент S-box, ограниченного семейства 1024 ключей и побитовых зависимостей расписания. Полный перебор 16-битной модели, включая опубликованные неблагоприятные результаты.
- Отдельный модуль `nastyx-message`: произвольные сообщения до 1 МиБ, внешний контекст до 64 КиБ, экспериментальные производные ключи по трём ролям, тег 128 битов и проверка перед дешифрованием.
- Каноническая сериализация с проверками длины, версии, флагов и хвостовых байтов.
- Nonce резервируется в persistent реестре до шифрования. Отдельные операции первой инициализации и открытия; потеря/повреждение метаданных не приводит к молчаливому сбросу. Проверены повторное открытие, параллельные отправители и незавершённые резервирования.
- Независимые Python-реализации, 185 новых блочных и 10 межъязыковых векторов сообщений, демонстрация и локальный benchmark.

## Проверки

```powershell
py -3 -m unittest discover -s tests -v
py -3 research/generate_v3_vectors.py --check
cargo test --workspace --locked
cargo fmt --all --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo run -p nastyx-message --example research_roundtrip
```

Локально использована Windows GNU Rust 1.99.0 и Python 3.12.10. Итог: 25 тестов Python и 16 тестов Rust, включая исторические варианты; форматирование и Clippy проходят. Демонстрация завершает шифрование и обратное расшифрование; тест максимального сообщения тоже проходит. CI настроен для Linux, Windows, macOS и MSRV 1.74; результаты удалённого запуска следует проверять отдельно.

Проверены одно-битные изменения каждого байта небольшой Rust-записи, однобайтовые изменения всех Python-векторов, неверные ключи/контексты, усечения, расширение, размеры, исчерпание счётчика, отказ хранилища и потеря метаданных. Тесты подтверждают поведение реализации, а не криптографическую невозможность подделки.

## Не закрыто

Полные differential/linear trails и hulls исходной ширины, полноценные атаки восстановления ключа, независимая оценка KDF/тега, формальные границы, постоянное время и гарантированное удаление секретов из памяти. Toy-модель v0.3 на некоторых малых числах раундов хуже прежней. Nonce-гарантия не покрывает откат/удаление реестра, несколько реестров для одного ключа, сетевые файловые системы и неподтверждённую Windows power-loss durability.

Не реализованы обмен ключами, аутентификация личности, защита от повторов, независимые направления, ratchet и прямая секретность. Это следующий сессионный этап, а не свойства текущего модуля сообщений.

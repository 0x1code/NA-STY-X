# Собственная S-box NA&STY-X v0.2

## Генератор

Вместо AES S-box используется собственная фиксированная перестановка 256 байтов. Она создаётся сетью Фейстеля из 12 раундов на двух 4-битных половинах. Это отдельная конструкция таблицы, а не дополнительный раунд 128-битного шифра.

Для кандидата `c` из `0..255`:

```text
state = (0x4E415859 + c * 0x9E3779B9) mod 2^32
для каждого из 12 раундов:
    T = [0,1,...,15]
    для j = 15..1:
        state = (1664525 * state + 1013904223) mod 2^32
        k = (state >> 16) mod (j+1)
        swap(T[j], T[k])
для каждого байта x:
    L = x >> 4; R = x AND 15
    для каждой таблицы T: (L,R) = (R, L XOR T[R])
    S[x] = (L << 4) OR R
```

Публичный линейный конгруэнтный генератор служит только воспроизводимому построению таблиц. Его константы не секретны; он не является криптографическим генератором. Остаток по модулю при перемешивании не обеспечивает равномерной выборки перестановок. Таблица не зависит от ключа. Обратимость следует из обратимости каждой 4-битной пары Фейстеля.

## Отбор и отрицательный результат

Исследованы все 256 кандидатов. Первоначальная цель `DU <= 10` и минимальная нелинейность компонент `>= 100` не достигнута ни одним кандидатом. Это отрицательный результат, а не выполненный критерий.

Для дальнейшего исследования выбран кандидат с минимальным кортежем `(максимальный модуль Уолша, DU, номер кандидата)`: **18**. Все оценки и полная таблица опубликованы в `research/results/sbox-v0.2-design.json`. Это ранжирование небольшой семьи, не оценка стойкости.

| Показатель | Собственная v0.2 | Прежняя AES S-box в v0.1 |
|---|---:|---:|
| Биективность | Да | Да |
| Дифференциальная равномерность | 10 | 4 |
| Максимальная вероятность для ненулевой входной разности | 10/256 | 4/256 |
| Максимальный модуль Уолша при ненулевой выходной маске | 64 | 32 |
| Минимальная нелинейность компонент | 96 | 112 |

По указанным дифференциальным и линейным метрикам новая таблица слабее прежней. Нельзя называть замену усилением шифра. Даже улучшение этих метрик в следующих кандидатах не заменит анализа всей раундовой функции, ключевого расписания и протокола.

## Воспроизведение

```powershell
py -3 research/sbox_design.py --check
py -3 research/generate_vectors.py --check
py -3 -m unittest discover -s tests -v
cargo test --workspace --locked
```

Python и Rust генерируют таблицу отдельно. Rust проверяет все 256 элементов против общего hex-вектора и отсутствие повторов. Лаборатория вычисляет полные DDT/Walsh-таблицы и проверяет их математические тождества. Доступ по секретному индексу остаётся зависимым от данных: проблемы побочных каналов не исправлены.

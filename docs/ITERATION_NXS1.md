# Итерация NXS1 / 0.4.0-alpha — 12 октября 2026

## Реализовано

- Rust `nastyx-session` и независимая Python reference без внешних crypto-зависимостей.
- Трёхсообщительный handshake по одноразовому внешнему секрету с проверкой двух ID,
  обоих challenge, SID и полного транскрипта; отдельный код сверки собеседника.
- Неподтверждённое состояние без API отправки/приёма.
- Два направления с независимыми цепочками и новым MK для каждой записи; потребляемый
  `OneTimeSealer`, аутентификация полного заголовка до выдачи текста.
- Ограниченная перестановка, явное удаление skipped keys, отказ при повторе/подмене,
  закрытие, отсутствие клонирования/экспорта live-состояния Rust.
- Три процесса демонстрации, реальный HTTP relay с ciphertext, интерактивные команды,
  закрытие/повторное связывание и настоящий перезапуск клиентского процесса.
- Каноническая спецификация, публичные межъязыковые векторы и пакет внешней оценки.

## Покрытие запрошенных свойств

| Свойство | Статус прототипа |
|---|---|
| Установление сеанса/проверка собеседника | Работает с заранее переданным одноразовым секретом и внешней сверкой; без public-key agreement |
| Ключ каждого сообщения/replay | Работают два направления, ограниченная перестановка и отказ при повторе |
| Прямая секретность | Старые ключи исключаются из логического состояния; односторонность и физическое удаление не подтверждены |
| Восстановление после компрометации | Новое внешнее связывание; автоматическая PCS отсутствует |
| Несколько устройств/хранение | Изолированные пары; без каталога/групп/синхронизации. Состояние в памяти, после сбоя новый сеанс |
| Независимая экспертиза | Материалы подготовлены; внешняя экспертиза не проведена |

## Выполненные проверки

Локальная среда: Windows, Rust 1.99.0 GNU, Python 3.12.10.

- 27 Rust-тестов: 16 прежних + 11 сессионных (включая межъязыковую сверку).
- 33 Python-теста: 25 прежних + 8 сессионных.
- 10 000 ограниченных Rust parser-случаев; 5 000 публичных случайных Python-входов
  плюс усечения/расширение/изменение записей. Это smoke fuzz, не полноценная coverage-guided кампания.
- Все 185 legacy и 185 v0.3 блоковых, 10 v0.3 message и handshake/4 session-message
  вектора сверены генераторами.
- `cargo fmt --all --check`, Clippy workspace/all-targets с `-D warnings`.
- Трёхпроцессный сценарий: оба направления, replay, tamper с последующей корректной
  доставкой, порядок 2/0/1, новое связывание, реальный restart и отклонение старых пакетов.
- CI дополнен сессионными векторами и демонстрацией. Успех удалённого CI не заявляется.

`research/results/e2ee-demo-v1.json` содержит фактические пакеты и публичные demo-тексты,
хеши источников, Python/platform. Секреты приглашений/цепочек не сохраняются в отчёте.
`docs/E2EE_DEMO.md` — читаемая трасса того же исполнения.

## Граница результата

Первый работоспособный E2EE-прототип получен для исследований/интеграции с тестовыми данными.
Заявление о безопасности реальных данных не сделано. Функциональные и негативные проверки
не закрывают криптоанализ собственных примитивов, физическое стирание, боковые каналы,
безопасное долговременное хранение и собственное согласование ключей через недоверенную сеть.

# NAXI — варианты знака N

Пять концепций для выбора направления. Это растровые эскизы; после подтверждения выбранная форма переводится в чистые векторные контуры для Lottie.

| Вариант | Направление |
| --- | --- |
| 01 — Monolith | Строгая цельная геометрия, скруглённые внешние углы и чёткие внутренние |
| 02 — Ribbon | Плавная непрерывная лента с мягкими поворотами и разделением складок |
| 03 — Vector | Технологичная угловая форма, диагональные разрезы и скошенные торцы |
| 04 — Orbit | Непрерывный округлый контур с петлёй, встроенной в диагональ |
| 05 — Soft | Мягкая скульптурная форма с органичными переходами |

## Общая спецификация

Один крупный знак N на квадратном холсте, мятный #57F4B4 на графитовом #202222. Без слова под знаком, кроме подписи варианта. Чистая композиция с широкими полями; форма подходит для последующего перевода в SVG. Без декоративных элементов и объёмных эффектов.

## Спецификации направлений

1. Solid geometric N, precise rounded outer corners, squared internal angles, balanced Swiss-tech silhouette, no hooks or holes.
2. Continuous flowing ribbon N with soft folded turns and deliberate negative-space separation, flat vector appearance.
3. Futuristic angular N, controlled 45-degree cuts and corner chamfers, two diagonal channels, crisp aerodynamic silhouette.
4. Thick continuous monoline N, round terminals, looping joints, subtle orbit-inspired sweep within the diagonal, no surrounding circle or separate dots.
5. Soft solid N, broad fluid diagonal, subtly tapered upright stems, asymmetrical pillowy joints and bold readable silhouette, no hooks or stem holes.

## Анимация надписи

После рисования NAXI последняя I уменьшается по высоте. Зелёная рисующая точка остаётся над ней и образует маленькую i. На этом рисование заканчивается. Орбита и внедрение точки в большой знак исключены. Большой знак ожидает выбора новой формы.

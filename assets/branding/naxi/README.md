# NAXI — векторный логотип

Векторная реконструкция выбранного мятного логотипа. Сохранены силуэт знака, круглый вырез, расположение элементов и характер надписи. Неровности растрового изображения заменены гладкими кривыми Безье; цвет сделан однородным. Это аккуратная перерисовка, а не побитовая копия исходного изображения.

## Быстрый старт

- Для After Effects 2025 откройте `after-effects/NAXI-Master.aep`.
- Для добавления в существующий проект запустите `after-effects/NAXI-Shape-Layers.jsx` через **File → Scripts → Run Script File**. Скрипт добавляет новую папку и композицию; существующие элементы проекта сохраняются.
- Для сайта используйте `svg/naxi-lockup.svg`, для отдельной иконки — `svg/naxi-mark.svg`.
- Для Illustrator или Inkscape откройте любой SVG: все буквы уже переведены в контуры, шрифты не требуются.

## Файлы SVG

| Файл | Назначение |
| --- | --- |
| `naxi-master.svg` | Полный логотип, прозрачный холст 1254 × 1254 |
| `naxi-on-dark.svg` | Полный логотип на графитовом фоне |
| `naxi-lockup.svg` | Знак и надпись на прозрачном фоне с компактными полями |
| `naxi-mark.svg` | Только мятный знак |
| `naxi-wordmark.svg` | Только белая надпись NAXI, прозрачный фон |
| `naxi-monochrome.svg` | Одноцветный тёмный логотип для светлого фона |

SVG содержат геометрические контуры. В них нет встроенных растровых изображений, внешних ресурсов или текстовых объектов. Основные элементы имеют постоянные ID: `mark`, `letter-n`, `letter-a`, `letter-x`, `letter-i`. Их можно адресовать при последующей веб-анимации. Круглый вырез в знаке является прозрачным отверстием с правилом заливки `evenodd`.

## Слои After Effects

Композиция `NAXI - Master`: **1254 × 1254**, квадратный пиксель, **30 кадров/с**, длительность **4 секунды**. Ключевые кадры пока не заданы.

1. `NAXI - Controls` — общий родительский Null для масштаба, положения и вращения.
2. `Mark - N` — знак; внутри группы находятся `Body` и `Circular counter`.
3. `Wordmark - N` — буква N.
4. `Wordmark - A` — буква A.
5. `Wordmark - X` — два контура буквы X.
6. `Wordmark - I` — буква I.
7. `Background - optional` — графитовый фон; заблокирован от случайного редактирования, его видимость можно отключить.

Знак, буквы и фон — настоящие **Shape Layers**. Якорные точки букв находятся у их центров, поэтому удобно делать появление с масштабированием или вращением. Положение и масштаб всего логотипа меняются через `NAXI - Controls`.

Для анимации кругового выреза откройте `Mark - N → Contents → mark → Circular counter → Path`. Геометрия выреза редактируется отдельно от наружного контура. Для перемещения, вращения или появления каждой буквы используйте её собственный слой.

Контуры заливочные. `Trim Paths` на них обходит границу фигуры; эффект прорисовки широкой ленты лучше строить маской либо дополнительной осевой линией. Для экспорта с прозрачностью отключите слой фона и выберите формат с альфа-каналом.

## Исходники и воспроизводимость

`source/build_vectors.py` содержит исходные кривые и создаёт SVG, `source/geometry.json` и автономный импортёр JSX. Требуется Python 3.10+, дополнительные пакеты для сборки векторов не нужны.

```text
python source/build_vectors.py
```

`source/render-preview.cjs` создаёт PNG из реальных SVG. Для него нужны Node.js и пакет `sharp`. PNG в `preview/` служат для просмотра; рабочие файлы остаются векторными.

`source/export-ae-project.jsx` предназначен только для отдельного пакетного экземпляра After Effects с пустым проектом: он создаёт AEP, сохраняет проверочный кадр и закрывает этот экземпляр программы. Для обычной работы используйте импортёр из папки `after-effects/`.

## Проверка

Проект создан и проверочный кадр отрендерен в **After Effects 25.2.2**. В композиции семь слоёв. Визуально проверены контуры знака, круглый вырез, надпись и соответствие SVG. Совместимость бинарного AEP с более ранними версиями After Effects не проверялась; для них предусмотрен исходный JSX.

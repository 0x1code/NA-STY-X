# NAXI — исходник N для Illustrator

`NAXI-N-Vector-03.svg` — векторная реконструкция исходного углового варианта №03. Холст 1254 × 1254, фон прозрачный. Две части N — независимые замкнутые контуры, без растра и шрифтов.

Откройте SVG через **File → Open** в Illustrator. Через **Layers** или **Direct Selection (A)** можно выбрать любую часть и её опорные точки. Для перемещения всего элемента используйте **Selection (V)**. После редактирования сохраните через **Save As → Adobe Illustrator (.ai)**.

`NAXI-N-Vector-03.eps` — дополнительный векторный формат с теми же двумя контурами.

Геометрия восстановлена по растровой концепции; это редактируемый векторный исходник, а не встроенная картинка.
